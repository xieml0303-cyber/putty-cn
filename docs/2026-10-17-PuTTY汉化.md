# PuTTY 0.85 中文版汉化记录

日期：2026-10-17

## 结论

- PuTTY 官方（Simon Tatham 版本）**没有中文界面**，从未提供多语言资源，界面文本全部硬编码在 C 源码里。
- 采用第三方开源汉化项目 **larryli/PuTTY**（原 Google Code puttycn 项目），基于 0.85 源码，本地编译出中文版 `putty.exe`。
- 中文版已可用，启动后窗口标题为「PuTTY 配置」。

## 为什么不直接改二进制

官方 exe 的界面字符串是 C 字符串，不是 Win32 资源，无法用 Resource Hacker 之类工具替换。
直接做字节替换受原字符串长度限制：UTF-8 一个汉字 3 字节，`Open`(4)、`Save`(4)、`Help`(4)、`Yes`(3)、`No`(2) 等短词根本塞不下中文，且多处字符串被重复引用，全局替换风险高。因此放弃二进制汉化，改用源码编译。

## 编译环境

- MSYS2 基础包：清华镜像 `msys2-x86_64-latest.sfx.exe`（41 MB，约 31 MB/s，1.3 秒下完），解压到 `C:\msys64`。
- pacman 源替换为清华镜像后安装：
  - `mingw-w64-x86_64-gcc` 16.2.0
  - `mingw-w64-x86_64-cmake` 4.4.4
  - `mingw-w64-x86_64-make` 4.4.1（附带 ninja）
  - `perl` 5.42.3（构建脚本需要）
- 源码：`https://github.com/larryli/PuTTY/archive/refs/heads/master.zip`（2.5 MB），解压到 `.workbuddy/putty-cn-src/PuTTY-master`，版本 0.85。
- 配置：`cmake -G Ninja -DCMAKE_BUILD_TYPE=Release`，18.6 秒通过。
- 构建：`cmake --build build --target putty -j`，288 个目标全部成功。

## 产物验证

- 文件：`putty.exe`，1,836,539 字节（官方英文版 1,341,080 字节）。
- 中文界面字符串：998 条，如「错误」「无法打开终端」「保存的会话」「连接被远程主机关闭」「确定要关闭本会话么」。
- DLL 依赖仅系统库：ADVAPI32、GDI32、IMM32、KERNEL32、SHELL32、USER32、comdlg32、msvcrt、ole32，无 MinGW 运行库，可独立运行。
- 启动实测：进程正常，窗口标题「PuTTY 配置」（英文版为 "PuTTY Configuration"）。
