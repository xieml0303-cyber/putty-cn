## 一、需求

1. 「退出时关闭窗口」固定显示「从不」，不改底层 `CONF_close_on_exit` 逻辑。
2. 删除原会话页蓝框内的选项（关于/帮助等按钮及多余控件）。
3. 原红框区域改为「历史连接记录」：填入主机名/IP 后点「打开」自动记录；点记录条目把内容填入「保存的会话」下方候选框；历次 ssh/telnet 地址持久化保存。
4. 「载入(L)」改名「打开(L)」，只负责把选中的历史记录载入候选框，不直接发起连接；列表区域适当增大。

## 二、修改内容

### 1. 历史记录存储（新增持久化）

- `storage.h`：新增 `get_recent_hosts()` / `add_recent_host()` / `del_recent_host()` / `free_recent_hosts()` 接口。
- `windows/storage.c`：注册表 `HKCU\Software\SimonTatham\PuTTY\RecentHosts` 读写，值名 `0`、`1`…，`REG_SZ`，最新的在前；用 `snprintf` 构造值名避免边界问题。
- `unix/storage.c`：对应实现（供非 Windows 构建链接）。

### 2. 会话页逻辑（`config.c`）

- `struct sessionsaver_data` 增加 `history` / `nhistory` / `savedsession` 字段。
- `refresh_history()`：从注册表重读历史并重建列表。
- `select_history_entry()`：把列表选中项写入候选输入框。
- `sessionsaver_handler()`：
  - 列表 `EVENT_SELCHANGE` / 双击 → 载入到候选框；
  - 「打开(L)」→ 只调用 `select_history_entry()`，未选中时提示「请先在历史连接记录中选择一条记录」，**不发起连接**；
  - 底部「打开(O)」→ 读候选框地址（为空时回退到列表选中项），`conf_set_str(CONF_host)`、`add_recent_host()` 后 `dlg_end(1)` 发起连接；
  - 「删除(D)」→ 删除选中记录并刷新列表；
  - 「保存(V)」→ 保存到「默认设置」并弹出「保存成功」提示。
- `config_coe_handler()`：新增「退出时关闭窗口」专用处理，`EVENT_REFRESH` 固定选中「从不」并在 `EVENT_SELCHANGE` 回退，底层 `CONF_close_on_exit` 始终 `FORCE_OFF`（仅展示层锁定）。
- 布局：列表区域加高；「打开(L)」「删除(D)」置于列表右侧；「退出时关闭窗口」独占一行，标签完整显示。

### 3. 本轮修正

「打开(L)」原实现是直接连接（`conf_set_str` + `dlg_end`），与需求 4「仅控制载入候选框」不符，已改为只填充候选框。

## 四、排查记录：截图里的「127.0.0.1 自动填充」是残影

中途屏幕截图显示候选框里有 `127.0.0.1`，一度怀疑列表刷新时自动选中第一项。实测结论：

- 控件真实文本为空（`WM_GETTEXT` 长度 0），列表 `cursel=-1`；
- 旧进程窗口与新进程窗口位置尺寸完全相同，屏幕截图（CopyFromScreen）抓到了旧进程遗留像素；
- 用 `PrintWindow` 直接抓窗口后画面正常。

结论：无自动选中、无自动填充，属截图方式导致的误判。

## 五、保存目录改为全局唯一（2026-10-18 追加）

现象：点「保存(V)」后弹窗提示「配置已保存到「127.0.0.1」」，注册表 `Sessions` 下多出一个以 IP 命名的目录。

原因：保存分支把候选框内容 `ssd->savedsession` 当成了会话名传给 `save_settings()`，而 `open_settings_w()` 会用它创建注册表子键。

修改：

- `config.c` 保存分支改为 `save_settings("", conf)`，空名由 `open_settings_w()` 统一落到「默认设置」；弹窗文案固定为「配置已保存到「默认设置」，下次启动自动沿用。」
- 候选框里的地址只作为连接目标，不再参与保存路径。

清理：

- 备份误建键到 `backup/reg-session-127.0.0.1.reg` 后删除 `HKCU\Software\SimonTatham\PuTTY\Sessions\127.0.0.1`。
- 当前 `Sessions` 下只剩 `%E9%BB%98%E8%AE%A4%E8%AE%BE%E7%BD%AE`（「默认设置」）。

验证：候选框填入 127.0.0.1 后点保存，弹窗文案正确，注册表未新增目录（截图 `putty_savebox.png`）。
