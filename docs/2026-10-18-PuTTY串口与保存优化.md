# PuTTY 中文版：配置保存与串口默认值优化

日期：2026-10-18
仓库：https://github.com/xieml0303-cyber/putty-cn
提交：0446a85（已推送并验证远程 SHA 一致）

## 一、问题诊断

### 问题 1：配置界面「没有保存功能」

实测结论：**保存按钮和保存功能都正常**，根因是交互缺陷。

- 配置窗口右下角存在「保存(&V)」按钮，点击后能正常写入注册表（实测命名会话与默认设置均可保存）。
- 真正的问题在 `config.c` 的保存分支：当左侧「保存的会话」列表**没有选中任何项**时，点「保存」只执行 `dlg_beep()`（嘟一声）然后直接返回——没有弹窗、没有提示、什么也不保存。
- PuTTY 启动时会话列表默认**无选中项**，用户改完参数直接点保存，必然命中这条静默失败路径，表现为「保存了但退出后重置」。

### 问题 2：串口默认值不符合华为/华三标准

排查发现默认值分散在三处，且实际生效的是注册表：

| 来源 | 原值 | 华为/华三标准 |
|------|------|----------------|
| 源码 `be_list.c` 默认协议 | SSH | 串口 |
| 源码 `conf.h` 串口线 / 波特率 | 空 / 115200 | COM1 / 9600 |
| 源码 `conf.h` 流控 | None（正确） | None |
| 注册表「默认设置」键 | COM3 / 115200 / SSH / 流控 None | COM1 / 9600 / 串口 / None |

另有一个容易踩的坑：汉化版把默认会话名从 "Default Settings" 改成了「默认设置」，注册表中实际键名是 URL 编码的 `%E9%BB%98%E8%AE%A4%E8%AE%BE%E7%BD%AE`，英文版遗留的 `Default%20Settings` 键并不被读取。

## 二、修改内容

源码（larryli/PuTTY）共 3 处：

1. `be_list.c`：`be_default_protocol` 由 `PROT_SSH` 改为 `PROT_SERIAL`，启动即为串口模式。
2. `conf.h`：`serline` 默认值 `""` → `"COM1"`；`serspeed` 默认值 `115200` → `9600`。
3. `config.c`：未选中会话时点「保存」，不再 beep 返回，而是把 `savedsession` 置空、直接保存到「默认设置」。

注册表（本机生效配置）：

- `HKCU\...\Sessions\%E9%BB%98%E8%AE%A4%E8%AE%BE%E7%BD%AE`（实际读取的「默认设置」）：
  Protocol=serial、SerialLine=COM1、SerialSpeed=9600、SerialDataBits=8、SerialStopHalfbits=2（即 1 位停止位）、SerialParity=0（无）、SerialFlowControl=0（无）。
- 英文遗留键 `Default%20Settings` 的串口参数同步为 COM1/9600/无流控，避免混淆。

## 五、使用说明

打开 PuTTY 即处于串口模式，参数为 9600-8-1-无校验-无流控，串口线默认 COM1。接 USB 转串口线后把「串口线」改成实际端口即可连接。

改完任何设置后，直接点右下角「保存」即可存入「默认设置」（无需先选中会话），下次启动自动沿用。需要 SSH 时点选「SSH」单选按钮。
