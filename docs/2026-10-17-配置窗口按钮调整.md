# PuTTY 汉化版配置窗口按钮调整

日期：2026-10-17

## 需求

1. 删除配置窗口「关于」「帮助」按钮及其相关内容。
2. 把「保存」按钮移到原「关于」按钮的位置（窗口底部左侧）。
3. 点击「保存」后弹窗提示保存成功。

## 改动

| 文件 | 内容 |
| --- | --- |
| `config.c` | 保存按钮从会话页列表旁移到标准底部面板 column 0（原关于位置）；保存成功后调用 `dlg_info_msg` 弹「保存成功」提示 |
| `windows/config.c` | 删除 `about_handler`、`help_handler` 及关于/帮助按钮创建代码 |
| `dialog.h` | 新增 `dlg_info_msg()` 声明 |
| `windows/controls.c` | 实现 `dlg_info_msg()`：`MessageBox(MB_OK | MB_ICONINFORMATION)`，标题「PuTTY」 |
| `unix/dialog.c` | 实现 `dlg_info_msg()`（GTK 信息框，标题 Information） |

保存提示文案：

> 保存成功！
>
> 配置已保存到「默认设置」，下次启动自动沿用。

## 验证

- 编译：MSYS2 MinGW-w64 gcc 16.2.0，`cmake --build build` 通过，无错误。
- 界面：截图确认「关于」「帮助」已消失，底部布局为 [保存(V)] … [打开(O)] [取消(C)]，会话列表右侧只剩「载入(L)」「删除(D)」。
- 保存：点击保存按钮弹出蓝色信息图标提示框，标题「PuTTY」，内容如上，点「确定」关闭。
- 部署：`C:\Users\Wrok\AppData\Local\Programs\PuTTY\putty.exe`（1,836,489 字节）已更新。
