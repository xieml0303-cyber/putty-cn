# 串口下拉框「点任意位置展开」改造报告

## 改动内容

1. `src/windows/controls.c`
   - 新增 `readonly_combo_edit_subclass()`：只读组合框的 EDIT 子窗口子类过程。
   - `dlg_editbox_set_readonly()` 在置为只读时通过 `SetWindowSubclass()` 挂上该子类。
   - 子类在 `WM_LBUTTONDOWN` 且 EDIT 处于 `ES_READONLY` 时，向父组合框发送 `CB_SHOWDROPDOWN TRUE`，于是点击文本区任意位置都能展开列表；非只读状态不干预，正常编辑不受影响。
2. `src/cmake/platforms/windows.cmake`
   - `platform_libraries` 增加 `comctl32.lib`，因为 `SetWindowSubclass`/`DefSubclassProc` 来自 comctl32。

## 行为设计

- 只读时：点文本区、点箭头，都能展开下拉；键盘输入与粘贴仍被拦截。
- 可编辑时（SSH/Telnet 的 host 框）：点击文本区照常定位光标、编辑文字，不会误弹下拉。
- 页面切换导致控件重建时，`dlg_editbox_set_readonly` 会在每次刷新中重新挂子类，不会失效。
