# 统一部署位置 — 2026-10-19

## 背景

此前 `putty.exe` 同时存在于四处：`src/build/`、`dist/`、`C:\Users\Wrok\AppData\Local\Programs\PuTTY\`、`C:\Program Files\PuTTY\`，且版本互不相同（AppData 落后最新构建一天多，dist 里五个工具也落后）。用户要求统一到同一个地方。

## 执行内容

1. **同步 dist**：用 `src/build/` 最新构建覆盖 `dist/` 的 pageant、plink、pscp、psftp、puttygen，哈希与构建一致。
2. **备份英文原版**：把 Program Files 里六个英文原版 exe 复制到 `backup/*.orig-0.85-en`（putty 原版此前已备份）。
3. **提权覆盖 Program Files**：UAC 提权把六个汉化 exe 复制进 `C:\Program Files\PuTTY\`，覆盖英文原版。
4. **改桌面快捷方式**：`Desktop\PuTTY.lnk` 原指向 `dist\putty.exe`（曾一度指 AppData），现改指 `C:\Program Files\PuTTY\putty.exe`，工作目录同步为 `C:\Program Files\PuTTY`。
5. **删除 AppData 副本**：整个 `C:\Users\Wrok\AppData\Local\Programs\PuTTY` 目录删除（内含 putty.exe、旧 bak、putty.log）。

## 验证

- Program Files 六个 exe 与 `src/build/` 逐一 md5 比对全部 OK。
- `dist/` 六个 exe 与 `src/build/` 全部一致。
- 启动 `C:\Program Files\PuTTY\putty.exe`，窗口标题「PuTTY 配置」，中文界面。
- `puttygen.exe --help` 弹出「PuTTYgen 命令行错误 / 无法识别的选项 '--help'」中文错误框，确认汉化生效（该版本不支持 `--help`，属正常行为）。
- 桌面快捷方式目标路径已确认为 Program Files。

## 当前结构

| 位置 | 角色 |
