# 默认窗口尺寸 560×510 与初始位置左上角贴边

日期：2026-10-22
目标：把「默认设置」会话的窗口调到约 560×510 像素，且每次启动窗口固定在屏幕左上角（0,0）。

## 结论

| 项目 | 目标 | 实际 | 说明 |
| --- | --- | --- | --- |
| 窗口位置 | (0,0) | (0,0) | 精确命中，代码硬编码 |
| 窗口宽度 | 560 | 559 | 差 1px，字符格 10px 决定只能取 559 |
| 窗口高度 | 510 | 517 | 多 7px，行高 19px 决定 |

高度无法正好落在 510：19px 行高的整数倍对应窗口高度为 498（23 行）或 517（24 行）。取 517 是偏 7px 的更近解，498 会短 12px。

## 改动

1. `src/windows/window.c`：`CreateWindowExW/A` 的初始坐标由 `CW_USEDEFAULT` 改为 `0, 0`，两条分支（宽字符与 ANSI）同步修改，窗口启动即贴在主显示器左上角。位置不写入任何配置，因此每次启动都是左上角，不会记住上次拖动的位置。

2. 默认会话注册表键 `HKCU\Software\SimonTatham\PuTTY\Sessions\%E9%BB%98%E8%AE%A4%E8%AE%BE%E7%BD%AE`：
   - `TermWidth` = 52（DWORD）
   - `TermHeight` = 24（DWORD）

   注意 TermWidth/TermHeight 必须是 DWORD，写成字符串时 PuTTY 读取失败并回退到出厂 80×24。

## 尺寸换算依据（实测）

字体 DejaVu Sans Mono，FontHeight=12，DPI=96，字符格 10×19px；非客户区 33×59（菜单栏 18px + 垂直滚动条 17px）。

- 窗口宽 = 列数 × 10 + 39  →  52 列 = 559px
- 窗口高 = 行数 × 19 + 61  →  24 行 = 517px
- 校验：52×10+39 = 559 ✓，24×19+61 = 517 ✓（实测 CLIENT 526×458，NONCLIENT 33×59）

## 验证

用 `telnet 127.0.0.1 23` 起临时监听，`putty.exe -telnet 127.0.0.1 -P 23` 启动，取窗口矩形：

```
TITLE=127.0.0.1 - PuTTY
WINDOW pos=0,0 size=559x517
CLIENT=526x458
NONCLIENT=33x59
GRID=52x24
```

位置与网格均符合预期。三处二进制（`src/build`、`dist`、`C:\Program Files\PuTTY`）MD5 一致：`D178EB12920D12ECCCF46C5FBAA03FE0`。

## 部署

`C:\Program Files\PuTTY\putty.exe` 需要管理员权限，普通进程复制会被拒绝（`UnauthorizedAccessException`）。提权脚本：`reports/deploy-default-size-elevated.ps1`，由 `Start-Process -Verb RunAs` 拉起，结果写入 `reports/deploy-default-size.log`。

## 关闭时保存尺寸（原实现缺失）

上一版结论里写过「正常关闭会话会把窗口尺寸写回配置」，这是错的：这个版本里
`save_settings()` 只在配置对话框点「保存」时被调用（`src/config.c:988`），
关闭会话根本不写注册表，所以无论怎么拖，重开永远回到配置里的 52×24。

修复：`src/windows/window.c` 新增 `save_window_size()`，在 `WM_DESTROY`
（所有关闭路径的必经点，包括 Alt+F4、标题栏 ×、确认框点确定）里调用：

```c
static void save_window_size(WinGuiSeat *wgs, HWND hwnd)
{
    char *errmsg = NULL;
    settings_w *handle;

    if (IsZoomed(hwnd))
        return;                      /* maximised: rows/cols describe the monitor */

    handle = open_settings_w("", &errmsg);
    ...
    write_setting_i(handle, "TermWidth",  conf_get_int(wgs->conf, CONF_width));
    write_setting_i(handle, "TermHeight", conf_get_int(wgs->conf, CONF_height));
    close_settings_w(handle);
}
```

要点：

- 只写 `TermWidth`/`TermHeight` 两个 DWORD（由 `wm_size_resize_term()` 在每
  次 `WM_SIZE` 时刷新到 `wgs->conf`），不动会话里的主机、端口等其它设置。
- 保存的是行列数而非像素：下次启动由行列 + 字体度量重算像素尺寸，所以窗口
  仍然固定出现在 (0,0)，不会把拖动位置也记下来。
- 窗口最大化时跳过：最大化的行列数只是当前显示器的产物，记下来换到小屏幕
  会得到超出屏幕的窗口。

## 保存行为验证

测试步骤（脚本 `%TEMP%\test-save-size2.ps1` / `test-save-size3.ps1`）：
临时把 `WarnOnClose` 置 0（测完还原），启动 → 改动窗口尺寸 → 关闭 →
读注册表 → 再启动量窗口。

```
BEFORE term=52x24
START window=559x517
RESIZED window=700x620
EXITED=True
AFTER  term=66x29          ← 700x620 换算成 66 列 29 行并写回

CONFIG term=66x29
REOPEN pos=0,0  window=699x612  grid=66x29   ← 重开沿用
AFTER-MAXIMISED term=66x29   MAX-SKIPPED=True ← 最大化不覆盖
```

验证完毕后已把配置复位为 52×24（559×517），并把新构建部署到 `dist` 与
`C:\Program Files\PuTTY`，三处 MD5 一致：`1A1906C7BE13D74D4374A1FCD97E34CF`。
