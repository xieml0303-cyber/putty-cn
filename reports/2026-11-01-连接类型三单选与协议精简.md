# 连接类型三单选改造与 Rlogin/SUPDUP 协议删除

日期：2026-11-01
基线：main@`5574c33`
需求：主人——「其他：」旁的协议下拉框删除，替换为 Telnet；下拉框中的协议（Telnet/Rlogin/SUPDUP/Raw/裸 ssh 连接）相关引用与关联代码删除；三按键平均分布。

## 一、依赖核查结论（动刀前的彻查）

| 对象 | 依赖情况 | 处置 |
|---|---|---|
| Rlogin（rlogin.c） | 无外部依赖（CONF_localusername 为其专属，test_conf 有期望值行） | **连根删**：源文件、构建、枚举值、专属设置页、conf 字段、测试行 |
| SUPDUP（supdup.c） | 无外部依赖（CONF_supdup_* 四字段专属） | **连根删**：同上 |
| Raw（raw.c） | `putty -raw` 是自动化测试的字节流注入通道（verify_del_bytes.py 等） | **代码保留**，仅从界面消失（主人拍板） |
| 裸 ssh 连接（sshconn） | SSH 代理（sshproxy.c 注释）、连接共享（ssh/sharing.c:1994 比较 PROT_SSHCONN）、ssh.c 内部 bare_connection 机制 | **代码保留**，仅从界面消失 |

## 二、改动清单

1. **删除文件**：src/otherbackends/rlogin.c、src/otherbackends/supdup.c。
2. **src/otherbackends/CMakeLists.txt**：移除两行源引用。
3. **src/putty.h**：PROT_RLOGIN、PROT_SUPDUP 枚举值删除（无数组索引类数值依赖，grep 证实）；rlogin_backend、supdup_backend 声明删除；PROT_RAW 与 PROT_SSHCONN 保留。
4. **src/conf.h**：CONF_localusername 与 CONF_supdup_location/ascii_set/more/scroll 五个专属字段删除（注册表存量未知键 load 时自动忽略，安全）。
5. **src/be_list.c**：backends[] 删 rlogin/supdup 条目并更新注释（说明 raw/sshconn 保留原因）；be_default_protocol 不变（上轮已改 PROT_SSH）。
6. **src/config.c**：
   - 会话页：连接类型改三个单选（SSH/串口/Telnet，'t' 快捷键保留），ctrl_droplist 创建块、「其他：」按钮删除；两列布局（62/38，为 droplist 预留）改全宽单列，三按钮由 radioline_common 的 nacross 逻辑均匀分布。
   - struct hostport 删 protlist 字段；config_protocols_setdim() 整函数删除（droplist 灰化逻辑随之失效）；config_protocols_handler 简化（protlist 刷新/SELCHANGE 分支、「其他：」按钮的 -1 特判删除；存量已消失协议回退 SSH 并同步 Conf）。
   - 「连接/Rlogin」「连接/SUPDUP」两个专属设置页整块删除。
7. **src/test/test_conf.c**：localusername 与 SUPDUP 四项的期望值行删除。
