# 串口列表显示物理/蓝牙后缀

日期：2026-10-20
涉及版本：PuTTY 0.85-cn2（本地改造）

## 一、需求

串口下拉列表和编辑框里，每个串口名后面标注是物理串口还是蓝牙虚拟串口：COM3（物理）、COM4（蓝牙）。

## 二、实现

文件：src/config.c

1. 新增 strip_port_suffix()：按全角左括号「（」截断字符串，去掉后缀。
2. fill_serial_port_list()：
   - 列表项文本改为「端口名（物理）」或「端口名（蓝牙）」，蓝牙判定复用 serial_port_is_bluetooth()（读 HKLM\HARDWARE\DEVICEMAP\SERIALCOMM 的设备路径，含 BthModem 判为蓝牙）。
   - 回显编辑框时同样拼上后缀，常态就能看到标注。
   - 已保存的配置值先剥离后缀再和纯端口名比较，避免历史值带后缀时匹配失败。
3. config_host_handler() 的 EVENT_VALCHANGE：
   - 从下拉选择端口时，框架会把列表项文本（带后缀）写进编辑框，这里剥离后缀后再存入 CONF_serline。
   - 编辑框保持带后缀的显示，不回写纯值。

配置值始终是纯端口名（COM3 / COM4），带后缀的文本只用于显示，串口打开逻辑不受影响。

## 三、验证

用 Win32 API 读取配置窗口：

- 编辑框常态文本：COM3（物理）
- 下拉列表：[0] COM3（物理）、[1] COM4（蓝牙）、[2] COM5（蓝牙）、[3] COM6（蓝牙）、[4] COM7（蓝牙）
