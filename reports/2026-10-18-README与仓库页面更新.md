## 一、README 更新点

### 1. 串口默认配置（纠正过时描述）

原文写「默认串口线 COM1」，与现行实现不符。实际行为是：

- `conf.h` 中 `serline` 默认空串；
- 界面打开时枚举注册表 `SERIALCOMM`，把本机真实端口填入下拉框；
- 当前配置值不存在时自动回退到列表第一项，真实串口排在蓝牙虚拟口之前。

README 已改为「自动匹配本机真实端口（真实串口优先，蓝牙虚拟口后排）」，并补充下拉框只读、点击任意位置展开的交互说明。
