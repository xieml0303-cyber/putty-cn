# PuTTY 汉化版命令行工具汉化完成报告

日期：2026-10-18
范围：pscp、psftp、puttygen（Windows GUI 版）、plink 四条命令行/工具链
产物目录：`C:\Users\Wrok\Repos\putty-cn\src\build`

## 一、结论

pscp、psftp、puttygen、plink 四个工具的命令行帮助、参数校验、运行时错误提示已全部为中文。本轮补充修复了此前遗漏的两处：Windows 版 puttygen 的参数错误弹窗（11 条）与 plink 的全部运行时报错（8 条），并统一了三个控制台工具程序名前缀的冒号。

## 二、本轮发现的关键遗漏

前一轮汉化只覆盖 `pscp.c`、`psftp.c`、`cmdgen.c`。实际验证时发现两个盲区：

1. **Windows 版 puttygen 不走 `cmdgen.c`。** GUI 版 `puttygen.exe` 的参数解析在 `windows/puttygen.c` 的 `WinMain` 中独立实现，错误经 `opt_error()` 弹 MessageBox 显示。`cmdgen.c` 是控制台版本，Windows 构建不产出对应 exe，因此对 `cmdgen.c` 的汉化对 `puttygen.exe` 完全无效。用户实测 `puttygen --nosuch` 仍弹出英文 `unrecognised option '--nosuch'`，即由此引起。
2. **`windows/plink.c` 从未汉化。** 该文件 help 文本已是中文，但参数错误与运行时错误仍为英文，属于半成品状态。

## 五、关于 puttygen 不支持 --help

`puttygen --help` 报错不是汉化问题。上游 PuTTY 的 Windows GUI 版 puttygen 本就没有 `-h`/`--help` 选项（其选项仅 `-pgpfp`、`-restrict-acl`、`-t`、`-b`、`-E`、`-primes`、`-strong-rsa`、`-ppk-param`、`-demo-screenshot`），只有控制台版 `cmdgen` 提供 `-h`。保持上游行为，未擅自新增参数。

## 六、遗留事项

1. `windows/pageant.c` 仍有英文诊断信息（如 `unable to get user SID`、`wrong owning SID of file mapping`），多为内部错误与调试日志，是否汉化待定。
2. `unix/plink.c` 未汉化；当前交付物为 Windows 构建，不影响使用。
3. SSH 协议层错误提示部分来自 `ssh/` 共享代码，pscp/psftp/plink 共用，仍有英文残留。
4. `dist/` 目录当前只有 `putty.exe`，本轮四个工具的产物未复制进去；若发布包需要，需另行确认发布结构。
